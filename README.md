# Password Generator

**A simpler way to generate passwords, without sacrificing control.**

Password generators are nothing new. But many present too many options upfront, turning a simple task into something that requires unnecessary decisions.

I wanted to explore a different approach: **make the common experience effortless, while keeping the flexibility for those who need it.**

## The Approach

The interface is designed around three simple ideas:

- **Start immediately.** Open the page, get a password, and copy it. No setup required.
- **Reveal only what's needed.** Adjust the length first, with more detailed options available when needed.
- **Give users meaningful control.** Limit the number of digits and symbols, exclude confusing characters, and meet specific password requirements without complicated settings.

Small details matter too. Smooth transitions make changes easier to follow, while the layout keeps the password itself as the main focus across different screen sizes.

## Privacy First

Password generation happens entirely in your browser using secure randomness. Generated passwords are never sent to a server or saved by the application.

## The Bigger Picture

This project is less about reinventing a familiar tool and more about **rethinking how people interact with it**.

Sometimes, improving software isn't about adding more features. It's about making the existing ones easier to use.
